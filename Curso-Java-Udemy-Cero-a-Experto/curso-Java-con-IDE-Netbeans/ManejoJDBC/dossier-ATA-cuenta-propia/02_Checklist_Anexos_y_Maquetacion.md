### Reglas de calidad
1. **Una evidencia = una página clara** (escaneo legible, no foto borrosa).  
2. Numeración de páginas y pie: “Plan de Empresa — Ricardo [Apellidos] — Confidencial / uso administrativo”.  
3. No rellenar con prosa genérica de mercado sin fuente.  
4. Sustituir todos los `[...]` antes de enviar.  
5. Tono: técnico y prudente. Prohibido: “viabilidad absoluta”, “riesgo cero”, “CERTIFICO”.  
6. En el cuerpo del plan solo van remisiones tipo **“Véase Anexo A”**. El CV, diplomas y facturas se **pegan como páginas del anexo** al final (o tras cada bloque), no se escriben dentro del capítulo 2.
